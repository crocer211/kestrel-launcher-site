Windows Desktop Launcher • Rust + WebView2

Isolated Minecraft instances for Java & Bedrock, without the bloat.

Kestrel Launcher is a lightweight native Windows launcher designed to keep every modded setup, world, resource pack, and runtime cleanly isolated per instance.

Dual-Edition Isolation

Create independent Java Edition (Vanilla, Fabric, Quilt, Forge, NeoForge) and Windows Bedrock Edition instances with separate saves, packs, and settings.

Mods, Modpacks & Packs

Browse and install Modrinth and CurseForge mods, modpacks, shaders, and resource packs, or share compatible packs across instances.

Worlds, Servers & Diagnostics

One-click world backups, saved server list with live status ping, screenshot gallery, playtime tracking, and crash log analysis.

Native & Lightweight

Built with a native Rust backend and Windows WebView2 instead of bundling Chromium or an extra JVM for the launcher interface.

Microsoft Account Authentication

Kestrel Launcher uses standard Microsoft OAuth 2.0 to authenticate players with their own Microsoft accounts, verify Minecraft: Java Edition ownership, and obtain a session token to launch the game and join multiplayer servers.

All authentication tokens are stored locally on your Windows device and are sent only to official Microsoft, Xbox Live, and Mojang authentication endpoints. No credentials or tokens are ever transmitted to third-party servers.
